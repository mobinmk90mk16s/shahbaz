# وضعیت پیاده‌سازی Laravel MVC شهباز

## کد اجرایی تحویلی

- Controllerهای Storefront، Cart، Wishlist، Account، Authentication و مهاجرت داده مهمان.
- Modelهای User، Category، Product، Cart، CartItem، Wishlist، WishlistItem، OtpChallenge، GuestProfile، Role، Permission و AdminActivityLog.
- صفحات Blade برای خانه، دسته‌بندی، جزئیات محصول، جست‌وجو، سبد خرید، علاقه‌مندی‌ها، حساب کاربری، ورود و ثبت‌نام؛ به همراه Layout، Partial و Component.
- CSS جداگانه در `public/assets/css`; هیچ `<style>`، `style="..."` یا handler جاوااسکریپت inline در Bladeها استفاده نشده است.
- دارایی‌های واقعی CSS و تصاویر سورس فروشگاه در `public/assets` نگهداری شده‌اند. JavaScriptهای صفحه‌محور فقط روی صفحات مربوط بارگذاری می‌شوند.
- جست‌وجوی زنده و فیلتر دسته‌بندی از Endpointهای Laravel استفاده می‌کنند؛ صفحه‌بندی در سمت سرور است.
- Migrationهای افزایشی برای تکمیل users با موبایل، کاتالوگ، سبد، علاقه‌مندی، پروفایل مهمان، OTP، نقش‌ها، مجوزها و گزارش فعالیت مدیریتی.
- Seed داده‌های اصلی ۴ دسته و ۱۶ محصول موجود در سورس فعلی؛ Seeder حساب مدیر آزمایشی نمی‌سازد.
- ورود با موبایل/رمز، ورود OTP، ثبت‌نام با OTP، Hash کد و رمز، انقضا، محدودیت تلاش، Rate Limiting، چرخش Session و خروج امن.
- سبد و علاقه‌مندی سمت سرور، هویت مهمان با Cookie امن HttpOnly، Hash شناسه مهمان در دیتابیس و ادغام تراکنشی اطلاعات مهمان پس از ورود.
- مهاجرت یک‌باره LocalStorage قدیمی؛ کلیدها فقط پس از پاسخ موفق سرور حذف می‌شوند.
- زیرساخت RBAC و فرمان Console برای اختصاص مدیر کل به حساب موجود و تأییدشده؛ هیچ نقش مدیریتی از ورودی مرورگر پذیرفته نمی‌شود.
- درگاه پیامک با Contract و HTTP Adapter؛ پیامک تا زمان تنظیم API و اعتبارنامه واقعی سرویس‌دهنده ارسال نمی‌شود.

## تست‌های اضافه‌شده

- Unit: نرمال‌سازی موبایل ایران با ارقام فارسی/عربی و پیش‌شماره بین‌المللی.
- Feature: نمایش صفحات از دیتابیس، جست‌وجو، ذخیره سبد و علاقه‌مندی مهمان، اعتبارسنجی گزینه‌های محصول، ورود با رمز، رد حساب غیرفعال، خروج، ثبت‌نام OTP و مصرف یک‌باره کد.
- Browser/E2E: صفحات عمومی اصلی، جست‌وجوی زنده، افزودن محصول به سبد و فیلتر موبایل با Playwright.
- Syntax بررسی PHP و JavaScript انجام شده است. PHPUnit و مرورگر در محیط ساخت این بسته اجرا نشده‌اند؛ اجرای نهایی باید در Checkout محلی با `vendor`، دیتابیس MySQL، Node و مرورگر Playwright انجام شود.

## موارد خارج از دامنه فعلی

- چرخه سفارش، انبار واقعی، نرخ ارسال، Checkout، درگاه پرداخت و Callback پرداخت در سورس فعلی وجود نداشتند و در این تحویل شبیه‌سازی نشده‌اند.
- رابط کاربری پنل مدیریت طبق درخواست فعلاً ساخته نشده است؛ فقط زیرساخت داده نقش/مجوز و ثبت فعالیت مدیریتی اضافه شده است.
- `is_limited_collection` فقط برچسب بازاریابی کاتالوگ است و موجودی انبار را نشان نمی‌دهد.
- SMS تا زمان تنظیم `SMS_HTTP_URL`، `SMS_HTTP_TOKEN`، `SMS_SENDER_ID` و تطبیق Payload با مستندات سرویس‌دهنده واقعی فعال نیست.

## ایمنی عملیات

- Migrationها افزایشی‌اند؛ `migrate:fresh` اجرا نکنید.
- `.env`، `APP_KEY`، رمز دیتابیس و Token پیامک داخل ZIP نیستند و نباید Commit شوند.
- این فایل ZIP برای اعمال روی Checkout محلی شاخه `main` است؛ به‌تنهایی به GitHub Push نشده است.
- ZIP یک بسته Overlay برای ریشه پروژه موجود است، نه پروژه مستقل و نه جایگزین `vendor/` یا `.env`.
